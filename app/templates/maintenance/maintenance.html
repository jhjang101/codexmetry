System Snapshots

DB Snapshots are Self-Healing SQL files generated via pg_dump. They contain the complete structure, data, and sequences required to rebuild the DB on a standby server (PC-2).
Full System Archive creates a ZIP file including the DB Snapshot and Assets in the Uploads folder.

Forensic Policy: Use DB Snapshots for daily data protection. Use Full System Archives (SQL + Uploads folder) weekly or before major server migrations to ensure physical documents remain synced with database records.
